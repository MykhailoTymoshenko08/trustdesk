# Homework

Short math tasks that a tutor assigns to a child after a Lumo lesson, solved in the kids' app.

## What it does
- After each lesson the child gets 5-10 practice tasks matched to the topic of the lesson.
- The child solves them in the app; answers are checked automatically.
- The parent sees the result (score, time spent) in the family dashboard.
- The tutor sees the result before the next lesson and adapts the plan.

## Visibility rule
- Homework is visible only after the tutor marks the lesson complete.
- Until then the "Homework" tab of the lesson shows the empty state "Homework will appear after the lesson".
- Marking usually happens within 5-15 minutes after the lesson ends; it can take longer if the tutor is
  teaching back-to-back lessons.

## Rules
- One homework set per lesson; it expires 7 days after it was published.
- Unsolved tasks stay open; the child can resume at any time before expiry.
- Tutors can attach a custom task (photo or text) to the generated set.
- Trial lessons have a shorter set of 3 tasks.

## Surfaces
- Kids' app (tablet and web): "Homework" tab.
- Family dashboard: results and reminders.
- Tutor console: "Complete lesson" button and homework editor.

## Status
- Stable. Most homework tickets are about a "missing" set that is simply not published yet.
